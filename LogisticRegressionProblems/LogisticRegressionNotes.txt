Logistic Regression Definition:
    Logistic Regression is a supervised machine-learning algorithm used mainly for binary classification.
    It calculates a probability between 0 and 1 and then uses a threshold to decide the class.

In supervised learning , there are two types
    Regression - Linear Regression
    Classification - Binary classification and Multi class classification

for classification problems like spam / not spam , pass or fail
    we cant simply draw a linear line , beacuse data points are non linearly separable. 

in classification problems , we have to convert these points into probabily score or [0/1],
 we apply function to hypothesis that is y = b0 + b1x -> f(b0 + b1x) -> produces the 0/1 or prob score

 we use sigmoid score to convert values form -inf to +inf to 0 and 1 with continous increasing (0 0 0 0.1 0.3...)

sigmoid(x) = 1\1+e^-x

so , logistic regression formula is y = function(line equation) 
and compared with threshold to get a classification(pass or fail)

example:
Hours	Pass/Fail
1	0
2	0
3	1

model equation : z = wx + b

then convert z to probability equation : p = 1\1+e^-z

so the full model is p = 1\(1+e^(-(wx+b)))

step 2 : start with dumb values w =0, b = 0
z = 0x +0 = 0
p = 1\1+e^0 = 0.5 (e^0 = 1)

so intial values is 
x	Actual y	Predicted p
1	0	0.5
2	0	0.5
3	1	0.5

clearly the model has not learned anything yet

step 3: compute loss , we use Binary Cross Entropy loss
loss = −[ylog(p)+(1−y)log(1−p)]

formula behavior if actual is 1 we get loss = -log(p)
                 if actual is 0 we get loss = -(log(1-p))

calculate:
row 1 : y = 0, p = 0.5 loss = -(log(1-0.5)) = -log(0.5) = 0.693
row 2 : same that is 0.693
row 3 : y = 1, p = 0.5 , loss = -(log(0.5)) = 0.693

now avg of loss = 3(0.693)/3  = 0.693

this tells our current parameters is not good for model

step4: change w
∂Loss\∂w ​= 1/n​∑(p−y)x  we are calculating the loss with respect to weight mean , how loss changes
                        when we change the weights

similarly for bias,

∂Loss/∂b ​= 1/n ​∑(p−y)

therefore calculate p-y
x	y	p	p-y
1	0	0.5	0.5
2	0	0.5	0.5
3	1	0.5	-0.5

Calculate weight gradient:
Row 1 : (0.5)(1) = 0.5
Row 2 : (0.5)(2) = 1
Row 3 : (−0.5)(3) = −1.5

adding them 0.5 + 1 + (-1.5) = 0 
it gives zero weight gradient , so this example is a little too symmetrical 

so improving dataset...

step6 : calculating bias gradient
    db = 0.5 + 0.5 - 0.5 / 3 = 0.1667

step 7 : update weights and bias 
wnew = w old - lr (dw) = 0 - 0.1(-0.1667) = 0.01667
bnew = b old - lr (db) = 0 - 0.1(0.1667) = -0.01667

Logistic Regression learns a linear decision boundary, uses 
sigmoid to turn the linear score into a probability, and uses a threshold to decide the class.


why using Binary Cross Entropy instead of MSE
MSE increases, but BCE increases much more aggressively when the model becomes confidently wrong.
example values
Prediction	MSE	BCE
0.9	    0.01	0.105
0.7	    0.09	0.357
0.5	    0.25	0.693
0.2	    0.64	1.609
0.01	0.9801	4.605

"Logistic Regression outputs probabilities using the sigmoid function. 
Binary Cross-Entropy is designed for binary probability predictions and heavily
 penalizes confident wrong predictions. More importantly, when BCE is combined with sigmoid, 
 the gradient simplifies to \(p-y\), giving a strong and effective learning signal. 
 MSE can also be used with sigmoid, but its gradient contains the additional 
 sigmoid derivative \(p(1-p)\), which can become very small and slow learning."

 example after derivating loss with respect to z 
 we get mse = 2(p-y)p(1-p) , p(1-p) comes from sigmoid derivate because
 derivative with respect to z involves p too dL/dp * dp/dz = dL/dZ

 dL/dp = 2(p-y) , dp/dz = p(1-p)

 now in BCE
 dL/dZ = p-y/p(1-p) * p(1-p) = p-y 

 so in BCE the extra term sigmoid derivate got cancelled.

 now actual = 1 and predicted = 0.1

 MSE = (p-y) = (0.1-1) = nearly -0.99 error huge ok
        second part -> p(1-p) = 0.1(1-0.1) = 0.1 * 0.99 = 0.0099
        now multiply two parts -> (-0.99)(0.0099) = -0.0098 very small for large error
        learns very slow
BCE = simply (p-y) = (0.1- 1) = 0.99 learns aggressively.
