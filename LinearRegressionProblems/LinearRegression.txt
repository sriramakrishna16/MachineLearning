Linear Regression:
    Linear regression is a supervised machine learning algorithm used to model and 
    predict a continuous numeric output variable based on one or more input features.
    It assumes that a straight-line relationship exists between your inputs and your output.

Linear regression is the process of predicting a numerical value with the help of best fit line.

Depending on how many features we use , the formula scales from a two dimensionlal line
    to multi dimentional hyperplane.

1.simple linear regression:
    y = b0 + b1x1 or y = mx + c , m = slope and c = intercept
2.multiple linear regression:
    y = b0 + b1x1 + b2x2 + b3x3 + b4x4 + ..... +bnxn

y - predicted output
b0 - intercept, represents the baseline value when all features equals zero
b1,b2,b3 - the coefficients or weights assigned to each feature. They act as multiplier
            determining feature impact
x1,x2,x3 - actual feature values

    for example : assuming b1 as area in house price prediction 
            x is actual feature value and b1 is coefficient 
            so, if b increases (area), feature value also increases

Evaluation methods:

we used to calculate the error to find the best fit line
    while calculating , change of error cancel each other 
ex
area price predicted error
5   20  15  5  
6   25  21  4  
7   30  25  5   
8   35  40  -5
now while calculating the total error , 3 and 4 row values get calcel each other
resulting in wrong error calculation

so we apply squares to the error i.e 5sq + 4sq + 5sq + (-5)sq , so negative values turn into positive
this is known as Sum of squared errors (SSE)

now if we find the average error -> that is Summation(actual - pred)sq / n then it is MSE(mean squared error)

so, when we observe that squaring changes the scale very large ex: 25L error , then
squaring produce very large scale value , so we apply sqrt to it 
then it is RMSE (Root mean squared error) summation(sqrt(actual-pred)sq)/n

MSE - punishes large errors heavily ,ex : 2 and 10 
     Mean absolute error - > 2 + 10/2 = 6
     MEan squared error -> 4 + 100/2 = 52 (10 error punished heavily)

and now we use RMSE to convert back into orginal unit of target value.

so based on error , we used to find the best fit line...! some line gives high error , some line give least
error
