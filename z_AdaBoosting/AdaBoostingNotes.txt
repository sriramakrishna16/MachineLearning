AdaBoosting Definition:
AdaBoost (Adaptive Boosting) is an ensemble learning algorithm that combines multiple weak learners, 
usually small decision trees, sequentially, giving more importance to the data points
that previous learners classified incorrectly.

simple a set of records are passed through base learner and predicts the value
and verifies the output and the outputs which are incorrect are only passed to the next
base learner which is connected sequentially

step 1: in ada boosting we compute initailly sampling weight for every record
    and build stumps , stumps mean a tree with depth only one
    so we create n seperate stumps where n = no of features

    so we have select first stump/decision tree from all stumps using entropy
    less entropy are considered as first stump

step 2 : so from the stump1 we get output as like 4 correctly classified and 1 incorrectly classified 
    then for the incorrect classification we have to find the total error

    that is summing up the sample weights of particular incorrect classified record
    in this case only one record so TE = 1/7

step 3 : calculate the performance of the stump 
    performance = 1/2 log ((1-TE)/TE) = 0.896

step 4 : update the weights 
    new sample weight = weight * e ^ performance = 1/7 * e ^ 0.896 = 0.349
    for correctly classified , new weight = weight * e ^ (-perf) = 0.05

    we can observe that the correctly classified weights are decreased and 
    incorrectly classifed weights are increased.

    we get normalised values by dividing with total updated weight that is 0.68
